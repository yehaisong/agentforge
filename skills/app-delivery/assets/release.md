# Release record

- State: [prepared / triggered / completed / verified / failed]
- Target and mechanism: [environment, workflow, branch/event]
- Revision and artifact: [commit, build/run identifier]
- Authorization: [user request covering release actions, or preparation only]
- Validation: [actual checks and outcomes; unrun checks]
- Configuration/migration impact: [relevant prerequisites and data changes]
- Recovery: [known previous artifact/revision and migration limits]
- Verification: [deployment result and post-release behavior, if performed]
- Open issue: [specific unresolved concern, or none]

Do not record credentials. State which evidence establishes each release status.
